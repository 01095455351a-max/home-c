# Claude Code 작업 지시서 — 해아림한의원 잠실점 리디자인

## 배경
- 운영 중인 사이트는 Hugo(Hugo Blox) 정적 사이트이며 Cloudflare Pages 로 배포됩니다.
- 콘텐츠(마크다운)는 그대로 두고 **시각 언어만** 아래 시안에 맞춥니다.

## 참고 파일
- `design/Haerim-Jamsil-Homepage-v2.dc.html` — 홈 전체 시안
- `design/Haerim-Detail-Tic.dc.html` — 특화 질환 상세페이지 시안 (틱장애)
- `design/tokens.css` — 색상·타입·간격·모양 토큰. **이 값이 기준입니다.**

두 HTML 파일은 브라우저에서 바로 열립니다. 값이 모호할 때는 시안의 인라인 스타일을 직접 읽어 확인하세요.

## 원칙 (반드시 지킬 것)
1. 형광 연두(`#00ED64`, `#00C455`)는 전면 제거합니다. 주 CTA는 `--hj-primary` (#00684A) 배경 + 흰 글자, 호버 `#023430`.
2. 버튼·배지는 pill(9999px), 카드는 12px, 큰 패널 16–20px, 입력 8px.
3. 카드 기본형: 흰 배경 + 1px `--hj-hairline` 테두리 + 그림자 없음. 호버에서만 `--hj-elev-2` + `translateY(-2px)`, 전환 170ms.
4. 어두운 면은 푸터 하나만. 본문 섹션은 흰색과 `--hj-surface`(#F9FBFA)를 번갈아 씁니다.
5. 본문 가독성: 17px / 행간 1.8, 리드 문단 18px / 1.85. 한글 본문에 700(bold)은 쓰지 않고 600까지만 사용합니다.
6. 이모지 사용 금지. 아이콘은 라인 스타일만.

## 작업 순서
1. `design/tokens.css` 를 `assets/css/tokens.css` 로 복사하고, 테마 스타일시트보다 **먼저** 로드되도록 `layouts/partials/head` 계열 파일에 추가합니다.
2. 웹폰트 로드: Plus Jakarta Sans(400/500/600/700) + Noto Sans KR(400/500/700). 한글은 Noto Sans KR 이 실제로 렌더링되므로 폰트 스택 순서를 유지하세요.
3. 테마의 색상·타입 하드코딩 값을 토큰 var() 로 치환합니다. 먼저 `rg -n "#00ED64|#00C455|font-size" assets layouts` 로 대상을 찾아 목록을 만든 뒤 진행하세요.
4. 헤더/푸터 파티얼을 시안에 맞춥니다.
   - 상단 유틸바(40px, `--hj-surface`) → 위치·휴진 안내 + SNS + 전화번호
   - 스티키 헤더(76px, 흰 배경, 하단 1px 테두리): 로고 · 6개 메뉴 · [전화 연결][상담예약]
   - 네비게이션은 `flex: 1 1 auto; min-width: 0; overflow-x: auto` — **`overflow: hidden` 은 쓰지 마세요** (좁은 폭에서 메뉴가 잘립니다).
   - 푸터: `--hj-footer-bg`, 4열(브랜드 / 주요 진료과목 / 진료 시간표 / 오시는 길·문의), 하단에 사업자 정보와 의료법 고지.
5. 홈 섹션 순서를 시안대로 정리합니다: 히어로 → 특화 질환 9카드(3열) → 원장 2인 → 2대 분과 클리닉 → 치료 방법 9개 → 원내 둘러보기 4장 → 치료 후기 3장 → 오시는 길·진료시간 → 원장 컬럼 3개 → 전화 상담 신청 → 푸터.
6. 상세페이지 단일 레이아웃(`layouts/diseases/single.html` 상당)을 시안대로 만듭니다: 브레드크럼 → 민트 그라데이션 히어로(제목 + 태그 + CTA 2개) → 본문(좌) + 스티키 사이드바(우 320px: 목차 / 상담 카드 / 진료시간) → 상담·오시는 길 → 푸터. 9개 질환 페이지가 같은 레이아웃을 공유하게 하세요.
7. 반응형: 1200px 이하 좌우 여백 유지, 1024px 이하에서 사이드바를 본문 아래로, 3열 그리드를 2열 → 1열로 단계적으로 접습니다. 모바일 버튼 높이는 44px 이상.
8. 접근성: 본문 대비 4.5:1 이상 확인, `img` alt 유지, 폼 필드에 `label` 연결, 포커스 링 제거 금지.

## 검증
- `hugo server` 로 홈 + 질환 상세 3개 이상을 확인합니다.
- 확인 항목: 형광색 잔존 0건 / 헤더 메뉴 잘림 없음 / 카드 그림자 규칙 준수 / 본문 17px·1.8 / 푸터 외 어두운 면 없음.
- 콘텐츠 문구는 수정하지 않습니다. 의료법 고지와 후기 면책 문구는 반드시 유지합니다.

# 해아림한의원 잠실점 홈페이지

Hugo + [Hugo Blox](https://hugoblox.com) 기반으로 제작된 정적 홈페이지입니다.
콘텐츠는 [plan.md](plan.md)의 인터뷰 자료를 바탕으로 구성했습니다.

## 문서

- 📘 **[제작 매뉴얼](docs/MANUAL.md)** — 로컬 실행, 폴더 구조, 콘텐츠 수정 가이드, 배포 방법
- 🐛 **[문제 보고서](docs/ISSUES.md)** — 해결된 이슈, 알려진 제약사항, 대기 중인 작업 목록

> 두 문서는 작업이 진행될 때마다 함께 업데이트됩니다.

## 빠른 시작

```bash
npm install
run-hugo-server.bat   # http://localhost:1314
```

자세한 내용은 [제작 매뉴얼](docs/MANUAL.md)을 참고하세요.
